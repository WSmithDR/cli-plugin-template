# Installing cli-plugin-template in Codex

## What Codex gets

Codex consumes this repository as a native plugin with shared skills.
For this project, Codex support is skills-only:

- no symlinks
- no MCP servers
- no apps or app templates
- no hook emulation

## Install

1. Open Codex.
2. Go to the Plugins directory.
3. Find `cli-plugin-template` and install it.
4. Restart Codex or refresh plugin data if the plugin does not appear immediately.

## Verify

Ask Codex to use one of the catalog skills, for example:

> use the `plugin-dev` skill

or ask it to audit a plugin feature gap.

## Updating

If Codex does not show the latest version, refresh the plugin data or restart Codex,
then reopen the plugin listing.
